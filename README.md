# Rocío cumple 7

Invitación de cumpleaños creada por ATRY Agency.

## Abrir

Abrí `index.html` en un navegador. El archivo incluye estilos, imágenes, fuentes y JavaScript; no requiere instalación ni compilación.

## Evento

Sábado 14 de noviembre de 2026, de 16:00 a 19:00 (Uruguay). La invitación contiene la ubicación, opciones para Google Calendar y Apple Calendar y confirmación por WhatsApp.

## Edición

Este repositorio contiene la versión autónoma. La información y el código están integrados en `index.html`.
